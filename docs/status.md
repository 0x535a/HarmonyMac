# 状态与验证范围

J514S 和 J316c 的记录日期分别为 2026-11-19 和 2026-11-24。各项结果对应各自的构建与测试环境。

## 原生验证

| 项目 | [Apple M3 Pro / J514S](devices/j514s-m3-pro.md) | [Apple M1 Max / J316c](devices/j316c-m1-max.md) |
| --- | --- | --- |
| 启动 | U393 外置 ext4 根盘可进入原装桌面并正常关机 | 内置 NVMe 上的独立 ext4 根分区可启动到桌面。使用仓库构建器产物的冷启动与 SMC 时序待复测 |
| 显示 | Asahi、内屏 KMS 和直送有实测。实验性全高内屏为 3024×1964 @ 120 Hz。最新候选使用单屏，实际呈现帧率待量化 | 3456×2160 @ 120 Hz 内屏，实测 Asahi 硬件渲染与 KMS 直送 |
| 输入与背光 | 触控板进入原装输入栈 | 键盘驱动已加载，实测触控板多指事件和背光调节 |
| Wi-Fi 和蓝牙 | BCM4388 可扫描、关联并获得地址。蓝牙可发现设备，配对和数据传输待验证 | BCM4387 已加载 Wi-Fi 固件，蓝牙创建了 `hci0`。Wi-Fi 入网和蓝牙 HDI 待验证 |
| 板载音频 | 实验性板载播放候选在实机上不稳定，扬声器保护与耳机切换待验收 | 功放和耳机编解码器已完成内核探测，PCM、原装音频 HDI、实体放音及扬声器保护待验证 |

## macOS 虚拟与宿主验证

截至 2026-11-19，macOS + UTM/QEMU 分项覆盖签名 HAP 的安装与冷启动持久化、虚拟 USB 音频与网络、FAT/exFAT 存储、虚拟相机和部分硬件服务。该轮也验证了原装锁屏、壁纸、输入解锁、图形直送及软件回退。每项的测试环境和原生复测要求见 [J514S 验证记录](devices/j514s-m3-pro.md#功能进展)。
